The primary methods to generate all permutations of a set or array include backtracking, Heap's algorithm, lexicographical ordering, and the Steinhaus-Johnson-Trotter algorithm. [1, 2, 3] 
## Common Methods to Generate Permutations## 1. Backtracking (Recursive DFS)

* How it works: Build permutations step-by-step by choosing an available element, exploring all sub-permutations of the remaining elements, and then backtracking (undoing the choice).
* Use case: Great for educational purposes and general algorithmic problems like LeetCode 46. [3, 4, 5] 

## 2. Heap's Algorithm

* How it works: Generates each permutation from the previous one by swapping a single pair of elements while leaving the other n-2 elements undisturbed. [6] 
* Use case: Highly efficient and minimizes data movement by performing swaps in-place without extra stack overhead. You can read more on [Wikipedia](https://en.wikipedia.org/wiki/Heap%27s_algorithm). [2, 3, 7] 

## 3. Lexicographical Generation (Next Permutation)

* How it works: Sorts the array initially to find the lowest arrangement, then repeatedly finds the next lexicographically (alphabetically/numerically) greater permutation until the highest order is reached. [1, 2, 8] 
* Use case: Efficient iterative approach that works well even with duplicate elements in a multiset. Detailed steps are available on [Wikipedia](https://en.wikipedia.org/wiki/Permutation). [8] 

## 4. Steinhaus–Johnson–Trotter Algorithm

* How it works: Generates permutations by swapping adjacent elements based on a specific pattern derived from 17th-century change-ringing.
* Use case: Useful when you need each consecutive permutation to differ by a swap of only two adjacent elements. [1, 6, 9]

To generate all subsets (also known as the Power Set) of a set or array, you can use several distinct approaches ranging from bit manipulation to recursive exploration. [1, 2, 3, 4] 
## Common Methods to Generate Subsets## 1. Cascading (Iterative)

* How it works: Start with an empty subset [[]]. For each number in your input, take all existing subsets, copy them, add the new number to the copies, and merge them back into the main list.
* Analogy: If you already have [] and [1], adding 2 means you copy them to get [2] and [1, 2], resulting in four total subsets. [5, 6, 7, 8] 

## 2. Backtracking (Recursive DFS)

* How it works: Think of this as a binary tree decision. For every element in the array, you make two recursive choices: either include the element in the current subset or exclude it.
* Use case: Highly intuitive for graph traversal and state-space search problems. [9, 10, 11, 12] 

## 3. Bit Manipulation (Bitmasking)

* How it works: A set of size N has $2^N$ subsets. You loop integers from 0 to $2^N - 1$. The binary representation of each integer acts as a mask, where a 1 bit means "include the element" and a 0 bit means "exclude it".
* Use case: Extremely fast for small sets (where N ≤ 30) because it relies on low-level CPU bitwise operations. [13, 14, 15, 16, 17] 

------------------------------
## Comparison of Methods

| Method | Time Complexity | Space Complexity | Best For |
|---|---|---|---|
| Cascading | $O(N \cdot 2^N)$ | $O(N \cdot 2^N)$ | Clean, easy-to-read iterative code. |
| Backtracking | $O(N \cdot 2^N)$ | O(N) (stack depth) | Modifying or filtering paths mid-way. |
| Bit Masking | $O(N \cdot 2^N)$ | O(1) (ignoring output) | Max performance on small datasets. |
